Fasi del Progetto

  1. Lettura del file di testo: il contenuto del file introduzione.txt viene letto e salvato in una variabile.
    2. Clicca qui per vedere come ho letto il file
  2. Rimozione della punteggiatura: si eliminano tutti i segni di punteggiatura dal testo.
    3. Clicca qui per vedere come ho rimosso la punteggiatura
  3. Suddivisione in frasi e tokenizzazione: il testo viene suddiviso in frasi e in parole (token).
    4. Clicca qui per vedere come ho tokenizzato
  4. Lemmatizzazione: ogni parola viene ridotta alla sua forma base (lemma).
    5. Clicca qui per vedere come ho lemmatizzato
  5. Embedding lemmi: si utilizza il modello "distiluse-base-multilingual-cased-v1" per rappresentare lemmi come vettori numerici.
    6. Clicca qui per vedere come ho impostato una funzione per trovare gli embedding dei lemmi
  6. Calcolo similarità lemmi - parola input: si calcola la similarità tra una parola in input e i lemmi usando il coseno di similarità (cos_sim).
    7. Clicca qui per vedere come ho impostato una funzione per trovare la similarità tra una parola input e un lemma qualsiasi
  7. Embedding frasi: si utilizza il modello "distiluse-base-multilingual-cased-v1" per rappresentare le frasi come vettori numerici, successivamente si salvano in un file json.
    8. Clicca qui per vedere come ho impostato una funzione per trovare gli embedding delle frasi
  8. Calcolo similarità frasi - parola input: si calcola la similarità tra una parola data in input e le frasi usando il coseno di similarità (cos_sim).
    9. Clicca qui per vedere come ho impostato una funzione per trovare la similarità tra una parola input e le frasi del testo
  9. Calcolo similarità frasi - frase input: si calcola la similarità tra una frase data in input e le frasi del testo usando il coseno di similarità (cos_sim).
    10. Clicca qui per vedere come ho impostato una funzione per trovare la similarità tra una frase data in input e le frasi del testo
  10. Implementazione chatbot: È stato implementato un semplice chatbot interattivo in stile ELIZA che risponde a tre tipi di input.
    11. Clicca qui per vedere come ho impostato il chatbot
